# RetireLab Release 6.5 — Fund Library

## New
- **Fund Library** replaces the old Add Fund control.
- Curated category tree with Popular, Global, US, UK, Europe, Japan, Emerging Markets, Multi-Asset, Income, Defensive and Bonds/Cash sections.
- Search by fund, provider, category, description, ticker or identifier.
- One-click **Add to portfolio** action with duplicate protection.
- Separate **Add your own fund** workflow for custom holdings.
- Stable library IDs and editable RetireLab planning defaults.

## Assumptions
- The Assumptions page now follows the active portfolio in both its overview and editable table.
- Library funds show their category and identifier.
- User edits are marked **User Override**.
- **Reset** restores a library fund's default return, volatility and correlation.
- Custom funds remain marked **User Defined**.

## Compatibility
- Existing projects and simulations remain compatible.
- Dynamic fund lists are preserved when projects or saved inputs are loaded.
- Zero-volatility assumptions remain valid when loading a project.

## Note
Vanguard does not offer a standard LifeStrategy 0% Equity fund. The library therefore includes the official 20%, 40%, 60%, 80% and 100% Equity range plus a global bond index option for a bond-only starting point.
