# RetireLab Release 6.9 — Complete Retirement Journey

## Accumulation stage
- New blue/teal Accumulation tab, visually distinct from green retirement management.
- Optional Calculate accumulation switch on the Dashboard.
- Current age, retirement age, current pension value and regular monthly pension investment.
- Monthly investment wording is jurisdiction-neutral and includes all money that reaches the pension.
- Optional inflation-linked contribution increases and a contribution stop age.

## Independent accumulation portfolio
- Uses the existing curated Fund Library.
- The accumulation portfolio is entirely separate from the retirement CORE portfolio.
- Editable allocation, return, volatility and correlation assumptions.
- Library and custom funds are supported.

## Projection results
- Conservative 10th percentile retirement pot.
- Expected median retirement pot.
- Optimistic 90th percentile retirement pot.
- Accumulation chart with percentile range and median path.
- Starting pot plus contributions compared with median investment growth.

## Retirement handoff
- Strategy now clearly begins Stage 2: Managing wealth.
- Use the median accumulation pot by default or override it manually.
- The applied value updates the retirement starting portfolio and retirement age.
- Accumulation settings and results are saved with each project.

## Scope
RetireLab models the amount entering the pension. It does not calculate tax relief, employer contribution rules or country-specific pension legislation.
