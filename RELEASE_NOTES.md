# RetireLab Release 6.1 — Compact Roadmap

## Improved
- Annual Review renamed Roadmap.
- Page width is capped for easier reading.
- Compact top-to-bottom workflow replaces the wide card grid.
- Funding split is shown visually between Cash and CORE.
- Good-year or weak-year rule is displayed as a badge.
- Previous CORE return is visible beside the selected age.
- Expandable “Why?” explanation.
- Opening and closing portfolio values are shown together.
- Age strip is tighter and easier to scan.

## Unchanged
- Same mixed-funding calculations introduced in Release 6.0b.
- Results still retains the full Monte Carlo uncertainty range.
- Tax remains excluded.
