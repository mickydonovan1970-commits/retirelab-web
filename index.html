Important limitations

This version uses a correlated-normal Monte Carlo model with editable assumptions. The cash rule is applied mechanically. It does not model tax, trading costs, fund fees separately, intra-year tax timing, changing correlations, or behavioural changes. The annual CORE return used by the rule is the investment return before withdrawals.
