SIPP cash reserve and withdrawal rule

Changing the total SIPP or cash amount automatically recalculates the CORE value while preserving the four fund percentages. Default interpretation of your rule: if the CORE return is 5% or less, the spending shortfall is funded from cash first. If it is above 5%, the model sells CORE investments up to 5% of the CORE value at the start of that review year and takes any remaining shortfall from cash. If either source is exhausted, the other source is used.

Important limitations

This version uses a correlated-normal Monte Carlo model with editable assumptions. The cash rule is applied mechanically. It does not model tax, trading costs, fund fees separately, intra-year tax timing, changing correlations, or behavioural changes. The annual CORE return used by the rule is the investment return before withdrawals.
